# Dialogentis · frontend

Интерактивный дизайн-прототип на React 19, TypeScript, Vite и React Flow. Интерфейс на русском, светлая и тёмная темы. Бэкенд не подключён; все агенты, диалоги и показатели явно демонстрационные.

## Запуск

Нужен Node.js 22.12+ или поддерживаемая более новая версия.

```sh
npm ci
npm run dev -- --port 5178
```

Открыть http://127.0.0.1:5178/agents/support/flow. Команды выполняются в каталоге `frontend`.

## Что попробовать

- В чате спросить «Где мой заказ?», затем отправить `12345`: появятся ответ и подсветка демонстрационного пути.
- Выбрать блок, изменить текст, перетащить, соединить, дублировать или удалить. Позиции и содержимое сохраняются в localStorage. Для доступа с клавиатуры есть список блоков.
- Добавить агента или намерение, перейти в другое пространство. Списки агентов фильтруются по пространству, намерения — по агенту.
- В списках выбрать обычное, пустое состояние, загрузку или ошибку. Состояния и часть фильтров записываются в URL.
- Переключить тему в верхней панели; открыть поиск через Ctrl/Cmd+K.
- Вернуть исходные данные через «Настройки» → «Сбросить демоданные».

## Границы прототипа

Тестовый чат работает по фиксированным локальным правилам, а не исполняет произвольно изменённый граф. Изменение текста блока приветствия отражается в соответствующем ответе. Передача агенту, HTTP-запрос, обучение, версии, каналы, приглашения, настройки хранения и аналитика показывают интерфейс будущих функций. Реальные запросы, обучение, публикация и отправка писем не выполняются. Копирование агента дублирует его карточку; история версий иллюстративная. Остальные агенты получают демонстрационный шаблон графа магазина для просмотра редактора.

Аутентификация и серверная изоляция арендаторов ещё не реализованы. Используйте только демонстрационные данные. Состояние чата сбрасывается при уходе с экрана; диалоги в журнале — отдельные фикстуры.

## Проверка

```sh
npm run typecheck
npm run build
CHROME_PATH=/absolute/path/to/chromium npm run test:smoke
```

Для smoke-проверки сервер должен работать на порту 5178; другой адрес задаётся через `BASE_URL`. Chromium задаётся через `CHROME_PATH`; браузер не скачивается при установке проекта. Проверка использует отдельный браузерный профиль и не меняет пользовательский localStorage. Она проходит основной диалог, сохранение графа, все маршруты, состояния списков, создание агента, разделение демоданных, тему, мобильную навигацию и сброс.

Дизайн: тема Terrazzo, Onest для кириллицы и JetBrains Mono для кода. Шрифты поставляются локально. Токены — `src/styles/tokens.css`, стили приложения — `src/styles/app.css`, фикстуры и демоправила — `src/model.ts`.

Требования к платформе находятся в `../docs/TECHNICAL_SPECIFICATION.md`. Текущий этап дизайна описан в `../docs/DESIGN_PROGRESS.md`. Начата реализация [бэкенда](https://github.com/dialogentis/backend): там находятся Compose и [журнал реализации](https://github.com/dialogentis/backend/blob/main/docs/IMPLEMENTATION_STATUS.md). Для совместного запуска клонируйте репозитории рядом и следуйте backend/README.md. Серверные бизнес-функции ещё предстоят; текущий UI пока использует localStorage.
