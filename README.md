# dialogentis: веб-интерфейс

Веб-интерфейс проекта.

Интерфейс обслуживается FastAPI из соседнего каталога backend; сборка и Node.js для запуска не нужны.

Редактор разделён на основное описание, намерения, сущности и сценарии. Отдельные вкладки предназначены для обучения и тестового диалога с диагностикой.

При недоступном API включается явно обозначенный режим просмотра: можно изучить и редактировать примеры агентов, конфигурации сохраняются только в localStorage текущего браузера. Обучение и отправка сообщений заблокированы; предсказания модели не имитируются. «Проверить подключение» повторно загружает приложение и пробует API.

Полная установка серверной части описана в backend/README.md. Источники опубликованной версии Sites находятся в /workspace/sites/atlas-agent-workbench; перед публикацией они синхронизируются с этим каталогом.
